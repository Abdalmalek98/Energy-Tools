How the sheets are read
  • The “Building Name” column on the form holds the room name; the facility name, floor, collector and date are taken from the sheet header and carried down to every row.
  • Ditto marks ( / // 〃 ) copy the value from the row above, across pages of the same file. Change a value and every ditto below it follows.
  • Short forms are expanded to the template’s dropdown values: NOR → Normal, IN → Internal, SM → Surface, R → Recessed, 6500 → 6500K, NO ceiling → No Ceiling, 60×60 ceiling → Panel, 2F → 2FT, T-8 → T8.
  • Room sizes written in the right margin (e.g. 4×5) become the area in column AA (20). Margin sizes that sit one row low are lined up and flagged.
  • Space type is grouped from the room name (X-RAY → CLINIC, CORRIDOR → LOBBY, MEDICAL WASTE → STORE, DATA ROOM → IT ROOM).
  • A hospital zone written in the header (e.g. “Main Hospital – Blood Bank”) goes into the Section box and is added to the building name.
